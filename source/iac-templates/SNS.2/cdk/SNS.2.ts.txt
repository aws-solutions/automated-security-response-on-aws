// SNS.2 — SNS topics should have delivery status logging enabled
//
// ASR remediation enables delivery status logging for all supported protocols on the SNS topic.
// To apply this fix, add the loggingConfigs property with entries for each protocol on your Topic construct.
// NOTE: <LOGGING_ROLE> — an IAM role that grants SNS permission to write
// delivery status logs to CloudWatch Logs.
